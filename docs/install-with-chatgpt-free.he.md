# מדריך התקנה מלא בעזרת ChatGPT החינמי

המדריך מיועד למי שרוצה להתקין ולהפעיל את WhatsApp Inbox בעצמו, בעזרת ChatGPT החינמי, בלי Claude Code ובלי כלי אוטומציה בתשלום. ChatGPT מסביר מה לעשות; אתם מעתיקים את הפקודות ומריצים אותן במחשב.

> **חשוב להבחין בין שני דברים:** אפשר להיעזר ב-ChatGPT החינמי כדי לבצע את ההתקנה של השרת והאפליקציה. אבל נכון למועד כתיבת המדריך, ChatGPT בתוכנית Free אינו מאפשר לחבר שרת MCP פרטי כמו זה של הפרויקט. לכן ההתקנה לבדה לא תאפשר לשאול את ChatGPT החינמי שאלות על הודעות WhatsApp. פירוט מופיע בפרק [חיבור ל-ChatGPT החינמי](#chatgpt-free-limit).

## מה המערכת עושה?

1. אפליקציית WA Forwarder בטלפון Android קוראת את ההתראות שמציג WhatsApp.
2. האפליקציה מעבירה את תוכן ההתראות לשרת Cloudflare פרטי שלכם.
3. השרת שומר את ההודעות במסד נתונים D1 ומוחק אותן אוטומטית לאחר תקופת השמירה שהוגדרה.
4. שרת MCP מאפשר לעוזר AI תומך להתחבר להודעות באמצעות מפתח אישי.

האפליקציה קוראת **התראות בלבד**. היא אינה פותחת את WhatsApp, אינה נכנסת לצ'אטים ואינה מסמנת הודעות כנקראו. הודעות שלא מופיעות בהתראה, כגון הודעות מצ'אט מושתק או מצ'אט שפתוח על המסך, עלולות לא להישמר.

## לפני שמתחילים

צריך:

- מחשב Windows 10 או 11. ההוראות בהמשך נכתבו ל-Windows.
- טלפון Android 8 ומעלה עם WhatsApp.
- חשבון Cloudflare חינמי: [פתיחת חשבון Cloudflare](https://dash.cloudflare.com/sign-up).
- חיבור לאינטרנט.
- התוכנות הבאות במחשב:
  - [Node.js בגרסת LTS](https://nodejs.org/en/download/) — גרסה 20 ומעלה.
  - [Git for Windows](https://git-scm.com/download/win) — כולל Git Bash.
  - [JDK 17 ומעלה](https://adoptium.net/temurin/releases/) — חשוב להתקין JDK ולא רק Java Runtime.
  - [Python 3](https://www.python.org/downloads/windows/) — בזמן ההתקנה מומלץ לסמן Add Python to PATH.

אין צורך להתקין Android Studio או Android SDK. סקריפט הבנייה מוריד את כלי הבנייה הדרושים בעצמו.

## כללי עבודה עם ChatGPT החינמי

- פותחים שיחה חדשה ב-ChatGPT ומבקשים ממנו להדריך לפי המדריך הזה.
- מבצעים בכל פעם שלב אחד בלבד.
- מעתיקים פקודה מהמדריך, מדביקים בחלון המתאים ולוחצים Enter.
- אחרי כל שלב מעתיקים לכאן את הפלט שקיבלתם, כדי ש-ChatGPT יבדוק אם אפשר להמשיך.
- ChatGPT אינו מריץ פקודות במחשב שלכם. אתם אלה שמריצים אותן.
- **לעולם אל תדביקו בשיחה סיסמאות, מפתחות, קישורי הגדרה אישיים או כתובות MCP אישיות.** אם יש שגיאה, הסתירו קודם כל ערך סודי שמופיע בפלט.

אפשר להעתיק ל-ChatGPT את הבקשה הבאה:

```text
אני מתקין את WhatsApp Inbox לפי המדריך העברי שבמאגר.
הדריך אותי בעברית, שלב אחד בכל פעם.
תן לי פקודה מלאה להעתקה, הסבר היכן להריץ אותה,
וחכה שאשלח את הפלט לפני שתמשיך.
אל תבקש ממני לשלוח סיסמאות, מפתחות או קישורים אישיים.
אני משתמש ב-Windows וב-ChatGPT החינמי.
```

## שלב 1 — בדיקת התוכנות

פתחו חלון **שורת הפקודה (CMD)**:

1. לחצו על מקש Windows.
2. כתבו `cmd`.
3. פתחו את ״שורת הפקודה״.

העתיקו את הפקודות הבאות, אפשר את כולן יחד:

```cmd
node -v
npm -v
java -version
javac -version
python --version
git --version
```

מה צריך לראות:

- Node.js: גרסה 20 ומעלה.
- npm: מופיעה מספר גרסה.
- Java ו-javac: גרסה 17 ומעלה.
- Python: גרסה 3.
- Git: מופיעה מספר גרסה.

אם פקודה מחזירה הודעה שהפקודה אינה מוכרת, התקינו את התוכנה המתאימה מהקישורים בפרק הקודם, סגרו את CMD, פתחו אותו מחדש ובדקו שוב.

## שלב 2 — הורדת המאגר למחשב

בחלון CMD העתיקו את הפקודות הבאות. הן יורידו עותק של הפרויקט לשולחן העבודה:

```cmd
cd /d "%USERPROFILE%\Desktop"
git clone https://github.com/sh770/whatsapp-claude-inbox.git
cd whatsapp-claude-inbox
```

אם Git מציג שגיאה שהתיקייה כבר קיימת, אל תמחקו אותה. פתחו את התיקייה הקיימת ובדקו עם ChatGPT מה מצבה לפני שממשיכים.

## שלב 3 — התקנת רכיבי הפרויקט

ודאו שחלון CMD נמצא בתוך התיקייה `whatsapp-claude-inbox`. הריצו:

```cmd
npm.cmd install
```

הפקודה מתקינה את Wrangler ואת רכיבי הפרויקט הדרושים לפריסה ב-Cloudflare. המתינו לסיום. אם מתקבלת שגיאה, אל תמשיכו לשלב הבא לפני שבודקים אותה.

## שלב 4 — בניית אפליקציית Android

בשלב הזה משתמשים ב-Git Bash ולא ב-CMD:

1. פתחו בסייר הקבצים את התיקייה `whatsapp-claude-inbox` שנמצאת על שולחן העבודה.
2. לחצו עם הלחצן הימני באזור ריק בתיקייה.
3. בחרו **Open Git Bash here** או **Git Bash Here**.
4. בחלון שנפתח הריצו:

```bash
bash android/build.sh
```

בהרצה הראשונה יורדו קובצי בנייה, בערך 120MB. בסיום אמור להופיע נתיב לקובץ:

```text
public/wa-forwarder.apk
```

הסקריפט יוצר גם מפתח חתימה פרטי בתיקייה `android/signing`. **חשוב מאוד לגבות את התיקייה הזאת.** עדכונים עתידיים של האפליקציה חייבים להיחתם באותו מפתח, אחרת Android לא יוכל להתקין אותם מעל הגרסה הקיימת.

חזרו לחלון CMD, ודאו שאתם עדיין בתיקיית הפרויקט, והריצו:

```cmd
mkdir ..\whatsapp-inbox-secrets
xcopy android\signing ..\whatsapp-inbox-secrets\signing-backup\ /E /I /H /Y
```

התיקייה `whatsapp-inbox-secrets` נמצאת מחוץ למאגר. שמרו עליה במקום פרטי ובצעו לה גיבוי פרטי נוסף. **אל תעלו אותה ל-GitHub ואל תשלחו אותה ב-ChatGPT.**

## שלב 5 — פתיחת חשבון Cloudflare

1. היכנסו אל [Cloudflare](https://dash.cloudflare.com/sign-up) ופתחו חשבון חינמי או התחברו לחשבון קיים.
2. אמתו את כתובת הדוא"ל אם תתבקשו.
3. פתחו בתפריט את **Workers & Pages**.
4. אם Cloudflare מבקש לבחור כתובת `workers.dev`, בחרו שם פנוי. כתובת זו תהיה חלק מכתובת השרת שלכם.

אין צורך למסור ל-ChatGPT את הסיסמה לחשבון Cloudflare.

## שלב 6 — חיבור המחשב לחשבון Cloudflare

חזרו לחלון CMD שנמצא בתיקיית הפרויקט והריצו:

```cmd
npx.cmd wrangler login
```

ייפתח דפדפן עם בקשת הרשאה של Cloudflare. בדקו שאתם מחוברים לחשבון הנכון ולחצו **Allow**.

אחרי שהדפדפן מאשר את החיבור, חזרו ל-CMD והריצו:

```cmd
npx.cmd wrangler whoami
```

הפקודה אמורה להציג את חשבון Cloudflare שאליו התחברתם. אל תמשיכו אם זה אינו החשבון שלכם.

## שלב 7 — פריסת השרת

ב-CMD, מתוך תיקיית הפרויקט, הריצו:

```cmd
npx.cmd wrangler deploy
```

הפקודה מעלה את השרת ל-Cloudflare. בפריסה הראשונה Wrangler יוצר את מסד הנתונים D1 ומעדכן את הקובץ המקומי `wrangler.jsonc` בפרטי המשאב.

בסיום חפשו בפלט כתובת שדומה לזו:

```text
https://whatsapp-inbox.<שם-העובד-שלכם>.workers.dev
```

זו כתובת השרת הציבורית שלכם. פתחו בדפדפן את הכתובת בתוספת `/health`. לדוגמה:

```text
https://whatsapp-inbox.<שם-העובד-שלכם>.workers.dev/health
```

התוצאה התקינה היא:

```json
{"ok":true}
```

**חשוב:** לאחר הפריסה הראשונה, אל תבצעו commit או push של `wrangler.jsonc` כפי שהוא, כי הוא עשוי להכיל מזהה D1 של החשבון שלכם. אל תשתפו את הקובץ הזה בפומבי.

## שלב 8 — יצירת סיסמת מנהל

צריך להגדיר סיסמה חזקה לדף הניהול. בחלון CMD הריצו:

```cmd
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

תופיע מחרוזת ארוכה. העתיקו אותה ושמרו בקובץ טקסט פרטי שנמצא מחוץ למאגר, למשל:

```text
ADMIN_TOKEN=כאן_מדביקים_את_הסיסמה_שנוצרה
SERVER=https://whatsapp-inbox.שם-העובד-שלכם.workers.dev
```

אפשר ליצור את הקובץ באמצעות Notepad ולשמור אותו בשם:

```text
whatsapp-inbox-secrets\secrets.txt
```

אל תכניסו את הסיסמה לקובץ בתוך תיקיית הפרויקט. אל תשלחו אותה ל-ChatGPT.

כעת הגדירו את הסיסמה ב-Cloudflare. ב-CMD הריצו:

```cmd
npx.cmd wrangler secret put ADMIN_TOKEN
```

Wrangler יבקש להזין ערך. הדביקו את הסיסמה שיצרתם ולחצו Enter. הערך נשמר כ-Secret ב-Cloudflare.

## שלב 9 — יצירת משתמש וקישור התקנה

1. פתחו בדפדפן את כתובת השרת שלכם בתוספת `/admin`.
2. הזינו את סיסמת המנהל שהגדרתם בשלב הקודם.
3. הזינו את שמכם ובחרו כמה ימים לשמור הודעות. ברירת המחדל היא 30 ימים.
4. לחצו על **Create user** או על כפתור יצירת המשתמש.
5. דף הניהול יציג קישור הגדרה אישי וקישור MCP אישי.

קישור ההגדרה האישי מוצג פעם אחת בעת יצירת המשתמש. העתיקו אותו ושמרו בקובץ הפרטי שלכם. שמרו גם את כתובת MCP, אם תרצו להשתמש בה בעתיד עם לקוח MCP תומך.

**שני הקישורים אישיים וסודיים.** מי שמחזיק בקישור ההגדרה יכול להגדיר את האפליקציה עם המפתח שלכם; כתובת MCP מכילה מפתח שמאפשר גישה להודעות. אל תפרסמו אותם, אל תשלחו אותם ל-ChatGPT ואל תכניסו אותם ל-GitHub.

## שלב 10 — התקנת האפליקציה בטלפון

שלחו לעצמכם את קישור ההגדרה בערוץ פרטי, או פתחו אותו בטלפון באמצעות קוד QR מדף הניהול.

פתחו את הקישור בטלפון Android ופעלו לפי המדריך המאויר בעברית:

**[מדריך התקנת WA Forwarder — שלב אחר שלב](install-app.he.md)**

בין היתר תידרשו:

- להוריד את קובץ האפליקציה ולהתקין אותו מחוץ ל-Google Play.
- לאשר ל-Chrome להתקין אפליקציות ממקור זה.
- להתמודד עם אזהרת Google Play Protect. אם נדרשת השבתה זמנית של סריקה, הפעילו אותה מחדש מיד לאחר ההתקנה.
- לאשר לאפליקציה גישה להתראות.
- לאפשר לה לפעול ברקע ולהחריג אותה ממגבלות הסוללה לפי הצורך.
- לבצע בדיקת שליחת הודעה מתוך האפליקציה.

הרשאת גישה להתראות רחבה: Android עשוי לאפשר לאפליקציה לראות התראות רבות. הפרויקט מעביר לשרת רק התראות של WhatsApp, אך יש להבין את משמעות ההרשאה לפני שמאשרים אותה.

## שלב 11 — בדיקה

באפליקציה בטלפון הפעילו **Send test message**. בדקו שמופיעים:

- **Active · forwarding**
- **Sent OK**

בדיקת הניסיון מאמתת את החיבור לשרת. היא אינה משמשת לקריאת תוכן ההודעות האמיתיות.

לאחר מכן אפשר לשלוח הודעת WhatsApp חדשה לטלפון ולבדוק שהמערכת קולטת אותה. זכרו שהודעות ישנות מלפני ההתקנה אינן נשמרות בדיעבד.

## חיבור ל-ChatGPT החינמי

**החלק הזה חשוב במיוחד:** ChatGPT החינמי יכול לעזור לכם להתקין את הפרויקט, להסביר שגיאות ולתת פקודות להעתקה. הוא אינו יכול, בתוכנית Free, להוסיף את שרת ה-MCP הפרטי של הפרויקט כאפליקציה מותאמת אישית ולקרוא ממנו הודעות ישירות.

לפי תיעוד OpenAI בנושא [חיבור שרתי MCP מותאמים אישית ל-ChatGPT](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt), האפשרות לחבר שרתי MCP מותאמים אישית מוגבלת לתוכניות נתמכות ואינה זמינה בתוכנית Free.

לכן:

- **כן:** להשתמש ב-ChatGPT החינמי כדי לקבל הוראות התקנה, להעתיק פקודות, להבין פלטי שגיאה ולבצע בדיקות.
- **לא:** להדביק ב-ChatGPT Free את כתובת ה-MCP ולצפות שהוא יתחבר אוטומטית להודעות.
- חיבור ישיר להודעות דורש לקוח שתומך בחיבור MCP מותאם אישית ובתוכנית שמאפשרת זאת. בפרויקט הזה החיבור המתועד הוא ל-Claude דרך Custom Connector; ייתכן שנדרש לכך מנוי Claude בתשלום.

אל תמסרו ל-ChatGPT סיסמת מנהל, קישור הגדרה אישי, מפתח אישי או כתובת MCP.

## פתרון תקלות נפוצות

| הודעה או בעיה | מה לבדוק |
|---|---|
| `node is not recognized` | Node.js לא מותקן או לא נמצא ב-PATH. התקינו מחדש ופתחו CMD חדש. |
| `git is not recognized` | התקינו Git for Windows ופתחו CMD חדש. |
| `javac is not recognized` | התקינו JDK 17 ומעלה, לא רק Java Runtime. |
| `Python 3 is required` | התקינו Python 3 וודאו ש-Git Bash מצליח למצוא `python3` או `python`. |
| `wrangler login` לא נפתח | נסו שוב מתוך CMD, בדקו חיבור אינטרנט והתחברות לדפדפן. |
| `ADMIN_TOKEN secret is not set` | חזרו על שלב 8 באותו חשבון Cloudflare שבו פרסתם את השרת. |
| דף הניהול מציג סיסמה שגויה | ודאו שהזנתם את הערך המדויק שהוגדר ב-Worker Secret. |
| האפליקציה מציגה 401 | פתחו את קישור ההגדרה העדכני והגדירו את האפליקציה מחדש. |
| הודעות מפסיקות להגיע | בדקו הרשאת התראות, פעילות ברקע ומגבלות סוללה. |

## שמירה על אבטחת המידע

- אל תעלו ל-GitHub קבצי סודות, מפתחות חתימה, קובצי גיבוי או קישורי משתמש אישיים.
- שמרו את `whatsapp-inbox-secrets` מחוץ לתיקיית המאגר.
- גבו את `android/signing` במקום פרטי. אובדן המפתח עלול לחייב הסרת האפליקציה לפני התקנת גרסה חדשה.
- בעל חשבון Cloudflare יכול מבחינה טכנית לגשת להודעות שנשמרו ב-D1. אם אתם משתפים משתמשים נוספים, הסבירו להם זאת מראש.
- ההודעות נמחקות לפי תקופת השמירה שהוגדרה לכל משתמש.
- התקנת APK מחוץ לחנות ומתן הרשאת גישה להתראות כרוכים בסיכון. השתמשו בפרויקט רק אם אתם מבינים ומקבלים זאת.
