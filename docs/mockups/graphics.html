Setup in three steps
You do three things. Claude Code does the rest.
1
☁

Open a Cloudflare account

Free plan. Verify your email, pick a workers.dev subdomain, click "Allow" for Wrangler.

🙋 You · 3 min
2

Install the app

Open your setup link on the phone, get past Play Protect, allow notification access and battery.

🙋 You · 5 min · guided
3
✳

Connect Claude

Add the connector URL in claude.ai → Settings → Connectors. Then just ask.

🙋 You · 1 min
🤖 Claude Code handles everything in between: dependencies, building and signing the APK, D1, deploy, admin password, your user, and a personalized install guide.
